Privacy Policy — Siddhashram Admin

Last Updated: August 13, 2026

Notice: The Siddhashram Admin application is an internal management tool restricted exclusively to authorized administrators and team members of International Siddhashram Shakti Centre.

International Siddhashram Shakti Centre ("we", "our", or "us") operates the Siddhashram Admin mobile application ("App"). This Privacy Policy outlines how administrative data is collected, processed, and secured.

Purpose of the App

Siddhashram Admin allows authorized personnel to manage daily Ashram activities, including publishing news releases, organizing event schedules, responding to devotee inquiries, managing volunteer applications, and broadcasting push notification updates.

Information Collected

1. Administrator Credentials & Profile

To ensure secure access and audit logging, we collect:

  • Administrator Name & Email Address
  • Assigned Admin Role & Access Permissions (e.g., Super Admin, Editor, Moderator)
  • Authentication Logs & Activity Timestamps

2. Content & Media Uploads

When administrators upload media assets (press clippings, event photos, YouTube links), these files are uploaded directly to secure Cloud Storage buckets managed by International Siddhashram Shakti Centre.

3. Technical Diagnostics

We collect device type, operating system version, and crash logs via Firebase Crashlytics to maintain app stability and prevent unauthorized access.

Data Handling & Confidentiality

  • All devotee inquiries, volunteer details, and administrative data are kept strictly confidential.
  • We never sell, share, or monetize administrative or devotee data with any third-party advertisers.
  • Access to administrative data is governed by strict Role-Based Access Control (RBAC).

Third-Party Services

The Admin App relies on Google Cloud & Firebase infrastructure for security:

  • Google Firebase Authentication: Role verification and secure sign-in.
  • Cloud Firestore & Firebase Storage: Real-time database and media hosting.
  • Firebase Cloud Messaging (FCM): Broadcasting alerts to user apps.

Data Security

All communications between the App and database servers are encrypted using TLS/HTTPS protocols. Database storage is protected with strict security rules and access controls.
