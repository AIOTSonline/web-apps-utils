Privacy Policy for Winkin Admin

Application: Winkin Admin Console
Provider: Winkin
Last Updated: August 27, 2026

1. Introduction

Winkin ("we", "our", or "us") provides the Winkin Admin mobile application for authorized store managers, staff, and delivery administrators. This Privacy Policy explains how information is handled within the application.

Winkin Admin is strictly a business tool used to manage grocery store inventory, product listings, operating hours, order preparation statuses, and customer delivery updates.

2. Information Handled & Managed

Order Fulfillment Data

To fulfill customer orders, authorized administrators access customer-submitted details including recipient name, delivery address, postal code, and ordered items. This information is used solely for order packing, dispatching, and delivery verification.

Authentication Data

Authorized staff log in using assigned administrative credentials. Authentication tokens are stored securely on the device to maintain active sessions.

Push Notifications

The application uses Google Firebase Cloud Messaging (FCM) to receive alerts when new customer orders are placed and to send status updates (Packed, Out for Delivery, Delivered) to customers.

3. Permissions Required

  • POST_NOTIFICATIONS: Required on Android 13+ to deliver order alerts to store staff.
  • INTERNET & ACCESS_NETWORK_STATE: Required to communicate with backend servers and synchronize order data.
  • VIBRATE & WAKE_LOCK: Ensures store staff do not miss incoming order alerts.

4. Third-Party Services

The application connects to standard cloud infrastructure services:

  • Google Firebase Cloud Messaging (FCM)
  • MongoDB Atlas (Database)
  • Vercel Cloud Infrastructure

5. Data Security

All administrative requests between the application and backend databases are encrypted using Transport Layer Security (HTTPS/TLS). We do not sell, rent, or trade store or customer information.

6. Children's Privacy

Winkin Admin is a business management tool intended solely for adult store administrators and staff. It is not intended for use by children.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with a revised "Last Updated" date.
